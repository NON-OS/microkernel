## Station address

Each boot draws a locally administered address from kernel randomness for the interface at rest; the card's factory address is never used (`userland/capsule_driver_iwlwifi/src/server/radio/address.rs`, `draw`). Each join runs under the network's own address, from a key drawn at the first join and kept across firmware restarts (`userland/capsule_driver_iwlwifi/src/server/radio/join/ready.rs`, `ready`). The address is derived from the key, the network's name and the security the join runs (open, PSK or SAE), never the BSSID (`userland/nonos_wifi_core/src/address/key.rs`, `AddressKey::for_network`). That security is read from the candidate's beacon, as the join reads it (`userland/nonos_wifi_core/src/address/kind.rs`, `Security::of_beacon`; `userland/capsule_driver_iwlwifi/src/server/radio/join/connect.rs`, `Radio::connect`). The key is new each boot, so a network sees a new device after every restart, and a router that pins a lease or filters by MAC address cannot follow it. The v2 label (`userland/nonos_wifi_core/src/address/key.rs`, `LABEL`) changes nothing beyond that. Before the join the link and MAC contexts are removed and added again under it (`userland/capsule_driver_iwlwifi/src/firmware/gen3/join/address.rs`, `readdress`). With no randomness the interface takes the fixed 02:00:00:00:00:01, only the passive scan runs and nothing is transmitted (`userland/capsule_driver_iwlwifi/src/firmware/gen3/up.rs`, `SCAN_IF_ADDR`). A join needs the radio up, a drawn address and the right command layouts (`userland/capsule_driver_iwlwifi/src/server/radio/join/ask.rs`, `can_join`); otherwise connect, disconnect and link are answered with -38 (`userland/capsule_driver_iwlwifi/src/server/control/route.rs`, `route`).

## Scanning

- The scan is passive: the request sets the firmware's forced-passive flag with a 110 ms dwell (`userland/capsule_driver_iwlwifi/src/firmware/gen3/scan/request.rs`, `request`; `userland/capsule_driver_iwlwifi/src/firmware/gen3/scan/consts.rs`, `GEN_FLAGS_FORCE_PASSIVE`, `DWELL_PASSIVE`). No probe request is sent. `iwlwifi_proofs` runs background sweeps and a hunt on the modeled firmware and checks that every request is forced passive, carries no probe request or SSID, and that no frame is queued (`userland/iwlwifi_proofs/src/serve_tests/quiet.rs`).
- The channels are the 2.4 and 5 GHz entries of the NVM that the world-safe domain allows, 38 of them with LAR; 14, 68 to 96, 169 to 181 and 6 GHz are not scanned (`userland/capsule_driver_iwlwifi/src/firmware/gen3/nvm/parse.rs`, `parse`; `userland/nonos_wifi_core/src/regdom/world.rs`, `world`). Transmit power is the firmware's, under the regulatory domain its MCC reply settles on.
- A sweep may run 150 ms per channel plus 2 s before it counts as stalled (`userland/capsule_driver_iwlwifi/src/firmware/gen3/sweep.rs:42-50`, `budget_ms`), and the next starts 3 s after one ends (`userland/capsule_driver_iwlwifi/src/server/radio/mod.rs:54-55`, `REST_MS`).
- While a scan runs, the serving loop wakes every 50 ms to pump it (`userland/capsule_driver_iwlwifi/src/server/runner.rs:25-27`, `SCAN_TICK_MS`).

## Joining

- A network saved as hidden is refused with -2, because this driver sends no probe and a hidden network's beacon carries no name (`userland/capsule_driver_iwlwifi/src/server/radio/join.rs:122-126`, `CODE_NOT_FOUND`).
- The hunt for the network's access points listens only, for one whole sweep; every beacon for the network becomes a candidate at the signal it was heard at, and the join takes the best, then the next if the access point ends that join (`userland/capsule_driver_iwlwifi/src/firmware/gen3/join/hunt/find.rs`, `hunt`; `userland/capsule_driver_iwlwifi/src/server/radio/join/attempt.rs`, `try_each`). It joins on the channel the beacon names when the domain allows it and it is near where the beacon was heard, else where it was heard, and passes over a beacon heard where the domain allows nothing (`userland/nonos_wifi_core/src/regdom/channel.rs`, `join_channel`).
- The policy is WPA3-SAE when offered, WPA2 otherwise, and only SAE for a network saved as WPA3 (`userland/capsule_driver_iwlwifi/src/server/radio/join.rs:163`, `JoinPolicy::WPA3_ONLY`). Unlike the RTL8821CE, this driver does not retry a failed WPA3 join with WPA2.
- The management and data queues take the numbers the firmware gives only if the device can have them (below 512, `IWL_MAX_TVQM_QUEUES`), neither is the command queue, and they differ; otherwise the join ends before any frame, and the queue the firmware holds is removed by its TID (`userland/capsule_driver_iwlwifi/src/firmware/gen3/join/bss/queues.rs`, `usable`; `userland/iwlwifi_proofs/src/join_tests/queues.rs`).
- The firmware is asked for 900 ms of time on the channel for the join (`userland/capsule_driver_iwlwifi/src/firmware/gen3/station/session.rs:43`, `JOIN_SESSION_MS`).
- An unanswered frame is resent every 300 ms, at most 6 times in a row, and the whole exchange gets 7.5 s (`userland/capsule_driver_iwlwifi/src/firmware/gen3/join/exchange/limits.rs:11-18`, `RETX_MS`, `IDLE_TRIES`, `EXCHANGE_MS`).
- Management and EAPOL frames go at the lowest basic rate and data at the highest basic rate; no rate scaling runs (`userland/capsule_driver_iwlwifi/src/firmware/gen3/station/rates.rs:28-32`, `IWL_TX_FLAGS_CMD_RATE`).

A join returns the RTL8821CE's status codes, plus -3 and -4 when the pairwise or group key does not go into the card (`userland/capsule_driver_iwlwifi/src/server/join_wire.rs:54-75`, `CODE_GROUP_KEY`); the panel texts are on the [Wi-Fi overview](../overview/security.md#what-a-join-answers). A deauthentication or disassociation from the access point ends the link (`userland/capsule_driver_iwlwifi/src/firmware/gen3/join/link.rs:34-44`, `parse_leave`). An access point unheard for 2 s is probed, and three unanswered probes 500 ms apart end the link (`userland/nonos_wifi_core/src/station/alive.rs`, `QUIET_MS`). Once keyed the station runs Linux v6.12's balanced power save (`userland/capsule_driver_iwlwifi/src/firmware/gen3/station/power.rs`, `mac_power`).

## Authority

The [manifest](../../../overview/glossary-linux-personality.md#manifest) asks for the [capability](../../../overview/glossary-boot-root-record.md#capability-word) mask 0xF8038: IPC, Memory, Crypto, Driver, DeviceEnum, Mmio, Irq and Dma (`userland/capsule_driver_iwlwifi/Capsule.mk:15-17`, `CAPSULE_REQUIRED_CAPS`). The service is `driver.iwlwifi0` on port 4228 (`userland/capsule_driver_iwlwifi/Capsule.mk:13`, `CAPSULE_SERVICE_ENDPOINT`). The kernel's spawn request holds no Debug in any build (`src/hardware/iwlwifi_capsule/spawn.rs:50-59`, `requested_caps`), so the driver's own console lines never reach the log. The Settings panel's stage line and the status reply are the record.
