# NONOS 0.9.2 release notes

What NONOS 0.9.2 adds, the hardware it runs on, what does not work yet, and how
to move an installed system to it.

NONOS 0.9.2 runs on every core of an x86_64 processor. The kernel starts every
CPU the firmware enables, up to 256, and schedules processes on all of them, in
every build profile. See [Scheduler and SMP](../kernel/scheduler-and-smp.md).

To try it, start with [Installing NONOS](../install/README.md). Once it runs,
[Using NONOS](../using/README.md) walks through the desktop and its programs.
