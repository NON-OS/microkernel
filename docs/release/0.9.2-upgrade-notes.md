# NONOS 0.9.2 release notes: Upgrade notes

Part of [NONOS 0.9.2 release notes](0.9.2.md).

## Upgrade notes

There is no in-place update in 0.9.2. To move an installed system to a newer
release, install the new release over the old one:

1. Get the image and write it to a stick ([Get an
   image](../install/get-an-image.md), [Write a USB
   stick](../install/usb-stick.md)).
2. Boot the stick, choose `Install NØNOS` in the boot menu and answer setup.
3. On the Disks screen choose the disk whose row says `NONOS installed`. The
   Confirm screen warns that its store and data volume are lost.
4. Type the disk's word, let the installer write and read back, remove the stick
   and restart.

What to know before you start:

- Nothing carries over from the old disk. The old store, the programs installed
  there, anything kept there and the old data volume are erased. The new disk
  gets setup's answers, the wallpapers they keep and the signed programs the
  stick carries. NONOS has no way to copy files off the old disk first.
- Write down the wallet's recovery words before you update. The sealed copy
  NONOS keeps does not open after a kernel or firmware change, and the old data
  volume is erased.
- On a machine with a TPM, booting a newer release's stick once raises the TPM
  rollback floor when that release raised its rollback index. The older system
  on the disk is then refused with `This kernel is older than allowed`, and
  there is no way back to it on that machine short of clearing the TPM, which
  loses every key the TPM derives. Without a TPM the loader keeps no floor, and
  Hardened and Air-Gapped refuse to boot.
- The data volume key and the key that seals saved Wi-Fi networks are derived
  under PCRs 0, 4, 7 and 9. After a firmware update or a Secure Boot change, the
  installed volume stays closed and saved networks read `Sealed under a
  different boot state`. The kernel never formats over a volume it cannot open,
  and putting the firmware and the Secure Boot setting back gives the old key
  back. Clearing the TPM loses these keys for good.
- Remove the stick after installing. While a stick that carries NONOS is plugged
  in, the kernel keeps the boot's state on it before any internal disk.
- An update from one release to another is not tested in this release.

[Update](../install/update.md) has the details and the code behind each step.
