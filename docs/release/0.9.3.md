# NONOS 0.9.3 release notes

What NONOS 0.9.3 adds, the hardware it runs on, what does not work yet, and how
to move an installed system to it.

In NONOS 0.9.3, Linux programs can open their own windows on the desktop
through a Wayland bridge, and the Monero wallet syncs over Nym and Anyone.
Linux programs get pseudo-terminals, and the standard image carries Wi-Fi
drivers for more chips. A disk installed by 0.9.3 can be updated in place to a
later release and keep its encrypted data volume. Each claim on these pages
names the file, commit or
evidence directory it rests on. The evidence is indexed in [Release evidence
for 0.9.3](../release-evidence/0.9.3/README.md).

To try it, start with [Installing NONOS](../install/README.md). Once it runs,
[Using NONOS](../using/README.md) walks through the desktop and its programs.
