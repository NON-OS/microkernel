# NONOS 0.9.2 release notes: Supported hardware

Part of [NONOS 0.9.2 release notes](0.9.2.md).

## Supported hardware

NONOS 0.9.2 runs on x86_64 machines with UEFI firmware. [The hardware support
matrix](../hardware/MATRIX.md) lists every chip and id the drivers match, with
its state and what that state rests on. By class:

| Class | Works | Partial, refused or not supported |
|---|---|---|
| Processor | x86_64, every core the firmware enables, up to 256; idle performance cores take new work first on Intel hybrid parts | aarch64 is a preview under QEMU; riscv64 does not build into a kernel |
| Platform | UEFI; TPM 2.0 over FIFO or CRB; Intel VT-d and AMD-Vi DMA and interrupt remapping | neither remapping has run on hardware; Secure Boot needs the NONOS db certificate enrolled; the power button reaches the desktop, which cannot power off |
| Display | the UEFI framebuffer; virtio-gpu | no native GPU driver |
| Storage | NVMe; AHCI SATA, Intel RST in RAID mode; Intel eMMC; USB mass storage on the machine's own ports; virtio-blk | a device behind Intel VMD is refused its interrupts under remapping, so it is not driven; the Intel eMMC host 8086:9d2b is served only beside a SATA controller; no SD card driver |
| USB | xHCI; HID keyboards, mice and tablets on the machine's own ports | devices behind a hub; EHCI, OHCI and UHCI controllers |
| Input | PS/2 keyboard and mouse; I2C-HID touchpads on Intel LPSS or an ACPI-declared controller | I2C-HID touchscreens; a PS/2 touchpad runs as a plain mouse |
| Audio | HD Audio analog outputs: speakers, headphones and line out | HDMI and DisplayPort audio; Intel SST and DSP-only machines; AMD ACP; microphones |
| Wi-Fi | Realtek RTL8821CE | Intel cards on SO platforms, modelled only; the other Intel cards from the 7260 to the AX210 family are refused; every other chip, Intel BE200 and BE201 among them, has no driver |
| Ethernet | virtio-net in a virtual machine | e1000, RTL8139 and the RTL8169 family carry a receive fault; e1000e, igc and USB adapters are in no image |

Real hardware, for Wi-Fi on RTL8821CE (scan, join, DHCP, DNS, browser), the
local Qwen model offline, the Linux programs sh, python3, sqlite3 and john, the
installer to an internal NVMe disk and booting from it, the I2C-HID touchpad on
Intel LPSS, the PS/2 keyboard with layouts, Intel HD Audio, the power button and
the volume keys: Works on an x86_64 laptop (Intel Gemini Lake, 8 GB), maintainer
hardware report, 6 October 2026; the image commit was not recorded.

Nothing else has been run on real hardware for this release. [Reporting a
machine](../hardware/report.md) says how to add a report for yours.
