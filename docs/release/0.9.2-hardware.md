# NONOS 0.9.2 release notes: Hardware

Part of [NONOS 0.9.2 release notes](0.9.2.md).

### Hardware

- Wired Ethernet through the e1000, RTL8139 and RTL8169 drivers receives no
  frames. `net.core` takes their answer to its first receive-batch probe as a
  yes, then drops every register snapshot they send back as an unreadable batch,
  so DHCP gets no lease through them. This is read from the code; no run on this
  commit shows it either way. Transmit and virtio-net are not affected. See [The
  receive fault](../drivers/ethernet/README.md#the-receive-fault).
- Devices plugged into a USB hub do not work. Plug keyboards, mice and USB
  sticks straight into a port of the machine. See [USB
  hubs](../drivers/usb/hubs.md).
- No 0.9.2 image carries the e1000e, igc or USB network drivers, so no Intel
  I217, I218, I219, I225 or I226 port, USB Ethernet adapter or USB tethering
  works. See [Intel Ethernet](../drivers/ethernet/intel.md) and [USB
  networking](../drivers/ethernet/usb-net.md).
- Intel Wi-Fi joins only on SO platforms, and only against a modelled device so
  far. It has no interrupt-driven operation, no firmware restart and no power
  save. See [Intel Wi-Fi](../drivers/wifi/iwlwifi.md#not-supported).
- The kernel brings up an Intel VMD's private PCI domain itself, but that has
  not run on a machine with a VMD. If the drive behind it does not show, set the
  firmware's storage mode to AHCI or turn VMD off. See [Intel
  VMD](../drivers/storage/vmd.md).
- The seal signs the loader for Secure Boot only with the NONOS db key. Unless
  that certificate is enrolled in your firmware, turn Secure Boot off and boot
  Standard; booting with Secure Boot on is not tested in this release. Hardened
  and Air-Gapped boots need a TPM, and the menu does not list the TPM under
  Air-Gapped. See [Requirements](../install/requirements.md) and [Boot
  modes](../install/boot-modes.md).
- The installer refuses a disk under 2177 MiB or with 4096-byte logical blocks,
  and never offers a USB disk. See [Install to
  disk](../install/install-to-disk.md).
- Physical memory above 64 GiB is not used. See [Frame
  allocator](../kernel/frame-allocator.md).
