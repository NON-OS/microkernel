# NØNOS 0.9.3.5 (development state, BETA)

This is the source of 0.9.3.5 as it lands on `main`. It is not the sealed
release: the signed, sealed image is produced separately, with the release
keys. Until then, every image built from this tree is a development image and
says BETA.

## What is in it

- **Compositor and graphics**
  - damage tracking, row kernels and GPU composite;
  - the Intel display sleeps on its own vertical blank;
  - virtio-gpu flush batching;
  - the swapchain and fence calls;
  - keyed per-window layers, window ids in routed input, and WM popups;
  - direct scanout through IOMMU-confined imports on Intel, with the
    indicator band on its own plane. A full-screen 1080p client composes a
    1,344-pixel band instead of 2,073,600 pixels.
- **App launch**
  - the token MAC checked once at install;
  - the clock page;
  - kill-on-deny for native capsules, while the Linux personality keeps EPERM;
  - random bytes ungated, in the cap table and in its handler;
  - per-CPU audit rings;
  - NONOSPK2 packs with per-page digests;
  - 27 capsules no longer hold Crypto.
- **Install, Marketplace and LibreOffice**
  - prebuilt app images, fetched four chunks at a time over Anyone;
  - resumable cached fetch;
  - the LibreOffice image;
  - SimpleX and DarkFi content from a clean tree;
  - a fast install route, built and off by default.
- **Hardening**: fuzzing found and fixed two faults in the AML interpreter
  (a field made from itself overflowed the stack; a slot that refers to itself
  leaked):
  - the source-path leak fixed;
  - TCP SYN normalisation and random SNI on;
  - Loopix cover traffic on at the low rate;
  - IOMMU path audit;
  - guard pages around surface views;
  - 24 fuzz targets in CI.
- **Formal model**
  - five properties proven in Lean with no `sorry`;
  - the Admin grant escalation found and fixed;
  - Admin split into AcpiOwner, PolicyPush and PowerControl, so no process
    holds Admin;
  - revoke bounded;
  - extraction of the gate code;
  - the static checks green.
- **Wayland apps**: one window per toplevel, real popups, frame pacing at the
  output's refresh, and presentation timestamps.
- **Files**
  - the user-files broker;
  - block reuse in the volume;
  - the `/u` deletion hole closed;
  - app homes seeded with the person's folders.
- **Hardware bring-up**
  - the battery root cause fixed: ACPI mode is entered before `_REG`, a
    stalled EC is tried again, and an unread `_STA` is no longer reported as
    "no battery";
  - the boot device enumeration;
  - late-published host drivers;
  - service readiness.
- **Lock screen**: a passphrase at setup, hashed with Argon2id through the
  keyring; auto-lock on idle; the trusted band.
- **nsh**: the attested post-quantum server.
- **Verification**: every proof crate runs in CI; 290 crates run in one lane,
  and the kernel proofs pass `cargo test --release` and `lake build` with no
  `sorry`.

## The capsule-spawn panic fix

The per-CPU audit rings built each CPU's 22,528-byte ring on its 32 KiB kernel
stack before moving it to the heap. Kernel stacks are adjacent and have no
guard page, so the first audited syscall on each extra CPU overwrote the saved
syscall frame of the process whose stack lies below; that process then returned
in ring 0 to address 0 or 0x200000000. The fix builds each per-CPU audit ring
on the heap and puts a guard page below every kernel stack, so any later
overrun faults on the CPU that caused it rather than in another process.
