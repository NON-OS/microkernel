# NONOS 0.9.2 release notes: Networking and privacy

Part of [NONOS 0.9.2 release notes](0.9.2.md).

### Networking and privacy

- Programs that open their own connections take their route from one rule in
  `nonos_route_link`. A default network that cannot be read counts as the Nym
  mixnet, never as Direct. When the chosen network is not running, the
  connection fails and says so, and nothing falls back to another network. See
  [Privacy networks](../using/privacy-network.md).
- The browser and the Terminal's `curl`, `git clone` and `git push` follow the
  default network, and a Browser window can switch its own. The Terminal's
  `ping`, `nslookup`, `pull` and `push` run only when Direct is the default. See
  [Which programs follow the
  choice](../using/privacy-network.md#which-programs-follow-the-choice) and [The
  Browser](../using/browser.md#which-network-a-page-leaves-through).
- The wallet reads the chain over Nym or Anyone and never directly. Under a
  Direct default it uses Nym, or Anyone when Nym is not running. See
  [Wallet](../using/wallet.md).
- Downloads for installs, Qwen models and Linux packages alike, go over the
  Anyone network whatever the default is. `qwen get --direct` in the Terminal,
  or `d` in the Marketplace, takes one Qwen download directly. See [Privacy
  networks](../using/privacy-network.md#which-programs-follow-the-choice).
- One Wi-Fi join engine serves both Wi-Fi drivers. It runs WPA2-Personal and
  WPA3-Personal (SAE) with CCMP. On a network that offers both, the RTL8821CE
  driver joins with WPA3 first, and joins again with WPA2 when WPA3 does not
  finish for any reason but a wrong password. See [Wi-Fi and
  networking](../using/wifi-and-networking.md#which-networks-can-be-joined).
- The Intel Wi-Fi driver boots firmware, scans and joins WPA2 and WPA3 networks
  on the SO platforms: AX211, and AX201 modules on those platforms. This path
  has run only against a modelled device. See [Intel
  Wi-Fi](../drivers/wifi/iwlwifi.md).
- The network drivers in the image draw a new locally administered station
  address at each bring-up instead of using the card's factory address. See
  [Threat model](../overview/threat-model.md).
