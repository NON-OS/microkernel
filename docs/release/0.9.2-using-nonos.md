# NONOS 0.9.2 release notes: Using NONOS

Part of [NONOS 0.9.2 release notes](0.9.2.md).

### Using NONOS

- The desktop cannot shut down or restart the machine. The Power key, from the
  keyboard or the ACPI power button, shows `Power off is not available from the
  desktop`; the power service is built but not started. To turn the machine off,
  hold the power button for four seconds. That forced power-off skips the memory
  wipe an orderly shutdown runs. When the kernel cannot read the power button
  itself, its log line points to a Shut Down menu that does not exist. See [Keys
  the desktop answers](../using/desktop.md#keys-the-desktop-answers), [Platform
  devices](../drivers/platform.md) and [Device secrets and
  keys](../security/device-secrets-and-keys.md).
- Files and Editor never ask for a file to be kept, so what you make there is
  gone at power off, even on an installed system. To keep a file, make it in the
  Terminal and run `keep` on it. See
  [Files](../using/files.md#what-is-kept-after-power-off).
- Without a TPM, an installed system keeps its data volume closed. See [After
  the install](../install/install-to-disk.md#after-the-install).
- Settings has no keyboard layout row, no switch to turn back on an app turned
  off at setup, and no shutdown. See
  [Settings](../using/settings.md#what-settings-does-not-have).
- The Wi-Fi notes in Settings and setup are older than the code: they say WPA3
  cannot be joined and open networks can. WPA3-Personal joins; open, TKIP,
  Enterprise and hidden networks do not. There is no IPv6 and no Wi-Fi in the
  `qemu` image. See [Limits in this
  release](../using/wifi-and-networking.md#limits-in-this-release).
- The Settings note under `Default network` says Qwen downloads take that
  network, and setup's Network route step describes model downloads under each
  choice as if they did. They go over Anyone whatever the default. See [Privacy
  networks](../using/privacy-network.md#which-programs-follow-the-choice).
- `net.nym` and `net.anon` start on every boot that starts the network, whatever
  the default. `net.nym` reaches for a gateway and `net.anon` builds a circuit
  even when nothing uses them. Your local network can see that this machine runs
  Nym and Anyone, under Direct too. See [Threat
  model](../overview/threat-model.md).
- A booted image carrying traffic through a live Nym gateway or a live Anyone
  circuit is not tested in this release; the route code passes its host tests.
  See [What is tested](../using/privacy-network.md#what-is-tested).
- For an Intel card it cannot start, the Settings panel suggests `USB Wi-Fi`.
  NONOS has no USB Wi-Fi driver. See [Intel Wi-Fi](../drivers/wifi/iwlwifi.md).
- Programs started with `linux` have no network, are told the machine has one
  CPU though the kernel runs their threads on any core, and keep nothing they
  write except through a `>` redirect. See [What does not
  work](../using/linux-programs.md#what-does-not-work).
- The Marketplace lists only the Qwen tiers: no Linux packages and no NONOS
  apps. It reads a signed catalogue built into the image, and `qwen get` reads
  another. In an image built without them every Marketplace tab is empty and
  `qwen get` exits with status 3. See [Marketplace](../using/marketplace.md) and
  [Qwen language models](../using/local-ai.md).
- The volume starts at full on every boot and is not kept. See [Sound and
  media](../using/audio.md).
- There is no login and no password. `Lock the screen` in the wallet hides
  balances and actions, and `Open the wallet` brings them back without a
  passphrase. See [First boot](../install/first-boot.md) and
  [Wallet](../using/wallet.md#what-the-wallet-does-not-do).
- The Terminal's `log` reads a copy of the console that only images built with
  `capsule-serial-debug` keep; `hardened` and `airgapped` images keep none. Most
  drivers hold no Debug, so their own lines never print: read the kernel's
  `[DRIVER-...]` and `[EXIT]` lines instead. Kernel lines written through the
  structured log never print anywhere, among them the `[CAP-DENY]` capability
  refusals and the `[DATA]` line that says a data volume stays closed for want
  of a machine key. See [Logging](../kernel/logging.md) and [Reporting a
  machine](../hardware/report.md).
