# NONOS 0.9.2 release notes: What is new

Part of [NONOS 0.9.2 release notes](0.9.2.md).

## What is new

### Install and keep a system

- Install NONOS on an internal disk. Choose `Install NØNOS` in the boot menu,
  `Install to this computer` in setup, or the Install tile on the dock. The
  installer shows what this boot proved and offers the NVMe, SATA, Intel eMMC
  and virtio disks it can write. You confirm with a short word for the disk, the
  last four characters of its serial when they are printable. It then writes the
  loader, the kernel, the package store and room for an encrypted data volume,
  and reads back every sector it wrote. See [Install to
  disk](../install/install-to-disk.md).
- An installed system keeps setup's answers, the values Settings keeps, saved
  Wi-Fi networks, the wallet's sealed files, Qwen models on the data volume,
  NONOS packages installed with `pkg install`, and files you keep from the
  Terminal with `keep`. Everything but the Qwen models is kept in the package
  store, which is not encrypted. Saved networks, the wallet's sealed files and
  the data volume need a TPM. The disk store holds up to 512 entries and 96 MiB
  of loaded files, the signed programs it already carries included. Files made
  in Files or Editor are not kept; see [Known issues](0.9.2-supported-hardware.md#known-issues) and
  [Files](../using/files.md#what-is-kept-after-power-off).

### Apps and the desktop

- About has a Proofs screen. Its headline says in one line whether this boot is
  attested and whether its traffic is anonymous, and a part that could not be
  read shows as unknown, never as a pass. See [About and its Proofs
  screen](../using/desktop.md#about-and-its-proofs-screen).
- A click on a window raises it and gives it the keyboard in the same press. See
  [Windows](../using/desktop.md#windows).
- Install a Qwen tier from the Marketplace's `Models` tab, or with `qwen get` in
  the Terminal. The model files download over the Anyone network, each must
  match its pinned SHA-256 before the tier counts as installed, and a chat then
  runs with no network connection. See [Qwen language
  models](../using/local-ai.md) and [Marketplace](../using/marketplace.md).
- Twelve more Linux programs come in standard images, built from pinned sources:
  `sqlite3`, `perl`, `tclsh`, `mruby`, `qjs`, `jq`, `gojq`, `rg`, `fd`, `nano`,
  `make` and `openssl`. Run them from the Terminal with `linux`, beside `sh`,
  `python3`, `lua`, `zstd` and `john`. See [Linux
  programs](../using/linux-programs.md).
- The keyring seals and opens the wallet's account key and recovery words for
  the wallet alone, so no other program can have the keyring open or replace
  them. A program that holds Crypto can still derive the key behind them itself,
  as [Security limits](0.9.2-security-limits.md#security-limits) says. See [Wallet](../using/wallet.md)
  and [Protections and limits](../security/protections-and-limits.md).
