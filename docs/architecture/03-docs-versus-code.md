# Where the documents and the code disagree

The project's documents under `docs/internals/`, `docs/kernel/`, `docs/abi/` and the comments in the code were read as claims and checked against the code at `551bbd34`. These are the disagreements that bear on the architecture. In each case the code is what runs; the document or comment is what a reader is told.

| # | Claim | Where it is made | What the code does | Where |
|---|---|---|---|---|

The only relocator that runs is `apply_relative_relocations`, which handles `R_X86_64_RELATIVE` alone, and no symbol resolution runs at all | `src/elf/loader/core/relocate.rs:49-110`, called from `src/elf/loader/core/loader/load_entry_into.rs:35` |

## How the disagreements were found

Each row came from reading the module's document and then following the named function to its callers with the method of [method.md](method.md). Rows 7 and 9 coincide with published audit findings; the audit's own NKA-2026-039 records further count and citation drift in the release documents, which this review does not repeat.
