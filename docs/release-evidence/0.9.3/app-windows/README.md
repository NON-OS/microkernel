# Linux programs in their own windows, eight screenshots

Eight screenshots of Linux programs from the Marketplace, each open in its own
window on the NØNOS desktop, taken on 29 October 2026 at 1920x1080 on a
development image (throwaway keys, not the sealed release). Each window is the
program's own, drawn through the Wayland bridge inside the NØNOS frame, with the
frame's title bar around it.

| File | Program | What it shows |
|---|---|---|
| [01-telegram.png](01-telegram.png) | Telegram Desktop | its welcome screen, with the Terminal that started it behind, where the log shows the refused calls |
| [02-keepassxc.png](02-keepassxc.png) | KeePassXC 2.7.8 | the welcome screen with Create Database, Open Database and Import File |
| [03-darkfi-app.png](03-darkfi-app.png) | DarkFi chat app | the channel list (#dev, #media, #hackers and more), with the P2P log in the Terminal |
| [04-simplex-window.png](04-simplex-window.png) | SimpleX | the native window asking for the person's name on first start |
| [05-mpv.png](05-mpv.png) | mpv | its window, with no file open |
| [06-foot.png](06-foot.png) | foot | its window with a shell prompt |
| [07-darkirc.png](07-darkirc.png) | darkirc | asking for a nick in the Terminal |
| [08-darkfi-wallet.png](08-darkfi-wallet.png) | DarkFi wallet (`drk`) | asking for a passphrase in the Terminal |

The last two run in the Terminal and have no window of their own. Each Terminal
shows the line `[LINUX] policy bound` with the box the program started in.
