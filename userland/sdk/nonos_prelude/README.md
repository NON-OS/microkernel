# nonos-prelude

Re-exports for an SDK app: `App` from `nonos_app`; `Canvas`, `Color`, `Control`,
`Rect` and `Widget` from `nonos_ui`; `Window` from `nonos_window`; and `exit`,
`log` and `yield_now` from `nonos_runtime`. `nonos_sdk::prelude` adds
`sdk_main!`. See [the libc and std page](../../../docs/handbook/userland/libc-and-std.md).
