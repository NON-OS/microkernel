# What each served Linux call tells a guest, and why that is acceptable.
# One line per call: name | discloses | why acceptable. tools/ratchets/
# disclosure.py fails when a served call has no line or a line names a call
# not served. Section 8 of the completion doc: a plausible constant over the
# truth wherever the truth is nobody's business; the machine must look the
# same from every guest on every install unless the person chose otherwise.
