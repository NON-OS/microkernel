# The box each Linux program the vendor ships runs in. nonos_linux_policy's
# build (build.rs, build/table.rs) hashes each program's file from the Linux
# userland build (NONOS_LINUX_USERLAND, set by userland/linux_userland/
# Policies.mk and tools/nix/capsules.nix; /bin/<name> is <name> there) and
# compiles its policy into nonos_linux_policy::vendor::TABLE, the one copy
# capsule_linux, the market and nonos_proof_abi all read. A program not
# named here runs in the owner's default box (UNLISTED_MASK).
#
# One program a line: its path in the store, then the services it is served,
# from WAYLAND NET_ANON NET_LISTEN_LO FILES_HOME MODELS_RO EXEC JIT TTY
# (FILES_USER is reserved, and refused, until something serves it), then
# optionally calls=<130 hex digits>, the set as nonos.prove's
# `[PROVE] syscall buckets ok=` line prints it. With no calls= every call may
# complete, until the owner's runs measure the set. A NET_ANON
# program may name where it reaches with dests=<item>,<item>..., each
# <IPv4>/<prefix>:<ports>, [<IPv6>]/<prefix>:<ports> or <name>:<ports>, the
# ports N or N-M (build/dests_arg.rs). Its list goes into the table beside
# the policy, whose net_dests_hash names it; without dests= it reaches any
# destination over the anonymity network.
#
# The Qwen conversation, three builds of one program, as chat_pick runs them
# (install/chat_pick.rs): AVX2, x86-64-v2 without it, and plain x86-64 under
# QEMU TCG. One box for all three: its window, the models it reads, and the
# terminal a `qwen` chat runs on. No network: /models is served only to a
# family without one. The measured set, when it comes, is the union of the
# plain build's run under QEMU and the AVX2 build's on hardware.
/bin/qwenchat               WAYLAND MODELS_RO TTY
/bin/qwenchat-x86_64_v2     WAYLAND MODELS_RO TTY
/bin/qwenchat-x86_64        WAYLAND MODELS_RO TTY
