# The Perl library a NONOS image installs with perl, at /usr/lib/perl5: one
# file a line, relative to that directory. tools/linux-userland/perl.sh copies
# these and proves each module loads from them alone; Userland.mk puts them
# in perl's package. Pragmas and the core modules scripts reach for most; no
# documentation, no toolchain (CPAN, ExtUtils, Module::*, Test2, TAP), no
# unicore tables, no re (its XS half links only as a loadable module) and so
# no Text::Wrap, and no Encode::Unicode (UTF-16 and UTF-32), whose XS half is
# not linked in.
